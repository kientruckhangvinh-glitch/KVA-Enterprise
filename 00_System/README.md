# 00_System

Thư mục gốc chứa toàn bộ hệ thống quy tắc, chuẩn mực và cách vận hành của KVA Enterprise trên GitHub. Mọi thành viên (kể cả AI agent) đều cần đọc thư mục này trước khi làm việc với repository.

## Cấu trúc

| File / Folder | Nội dung |
|---|---|
| `01_Governance/RULES.md` | Nguyên tắc quản trị chung, quyền hạn, phạm vi sử dụng AI |
| `01_Governance/Workflow.md` | Quy trình làm việc từ lúc nhận task đến khi merge |
| `01_Governance/Branch_Strategy.md` | Cách đặt tên và sử dụng nhánh Git |
| `01_Governance/Commit_Convention.md` | Chuẩn viết commit message |
| `01_Governance/Naming_Convention.md` | Chuẩn đặt tên file, folder, biến, hàm |
| `01_Governance/Folder_Structure.md` | Giải thích ý nghĩa từng thư mục cấp cao |
| `01_Governance/Security_Policy.md` | Quy tắc bảo mật, xử lý secret, phân quyền |

## Nguyên tắc đọc tài liệu

1. Tài liệu trong `01_Governance/` là **bắt buộc**, không phải gợi ý.
2. Khi có mâu thuẫn giữa tài liệu và thực tế code, tài liệu là nguồn đúng — cập nhật code hoặc cập nhật tài liệu, không để lệch nhau.
3. Mọi thay đổi vào các file trong `00_System/` cần được review kỹ, vì đây là nền tảng cho toàn bộ tổ chức.
