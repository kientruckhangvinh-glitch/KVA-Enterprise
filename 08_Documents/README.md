# 08_Documents - Kho tài liệu mẫu KVA-Enterprise

Thư mục này chứa các template biên bản, nghiệm thu và tài liệu kỹ thuật chuẩn của công ty.

## Cấu trúc thư mục
- **templates/**: Chứa các file template gốc (.md và .docx).
- **examples/du_an_mau/**: Chứa các ví dụ điền mẫu thực tế để tham khảo.

## Hướng dẫn sử dụng
1. Truy cập thư mục `templates/` để lấy file gốc.
2. File `.md` dùng để xem cấu trúc và chỉnh sửa nhanh trên GitHub.
3. File `.docx` dùng để in ấn, ký tên và lưu trữ hồ sơ chính thức.
4. Khi điền thông tin cho dự án mới, vui lòng copy file ra thư mục dự án riêng, **không sửa trực tiếp file trong thư mục templates/**.

## Cập nhật template
Nếu cần thay đổi cấu trúc template gốc, vui lòng tạo Issue hoặc Pull Request để trưởng phòng kỹ thuật duyệt.
